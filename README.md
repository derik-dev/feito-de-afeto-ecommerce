# Feito de Afeto

Página responsiva de papelaria digital, recriada a partir da referência visual fornecida. HTML, CSS e JavaScript com Vite.

```sh
npm install
npm run dev
```

O endereço local é exibido no terminal. Para gerar os arquivos de produção: `npm run build`.

Também é possível abrir `index.html` com o Live Server do VS Code (porta 5500). Os estilos e as imagens funcionam nos dois modos.

As oito imagens foram criadas com a ferramenta integrada ImageGen e estão em `public/images/`, em WebP. Os prompts estão em `docs/image-prompts.md`.

O catálogo inclui busca, categorias, detalhes dos produtos, favoritos e carrinho com quantidades. Favoritos e carrinho são salvos localmente no navegador. O formulário de contato prepara um rascunho local. Pagamento, envio de mensagens e entrega de arquivos precisam de serviços reais antes da publicação da loja.
